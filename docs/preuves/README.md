# Preuves

Ce dossier contient les captures et preuves des étapes importantes du projet.

## Contenu

Ajouter ici :
- Captures d'écran du pipeline CI/CD GitHub Actions
- Capture de la Pull Request de démonstration
- Capture du déploiement minikube (`kubectl get all`)
- Capture de l'application accessible via Nginx
- Capture de Prometheus avec les targets UP
- Capture du dashboard Grafana avec les 8 panneaux
- Capture des alertes Prometheus fonctionnelles
- Capture de la persistance SQLite après redémarrage de pod

## Format

Les captures peuvent être au format :
- PNG / JPG (captures d'écran)
- TXT (extraits de logs)
- MD (logs formatés)
